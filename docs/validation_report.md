### Directed scenarios exercised

1. Master 0 writes and reads target 0.
2. Master 1 writes and reads target 1.
3. Partial byte-strobe write preserves untouched bytes.
4. Masters write to different targets concurrently.
5. Two masters contend for target 0; both writes are checked by readback.
6. Simultaneous reads from two masters contend for target 0.
7. B and R responses are deliberately backpressured for two clock edges before the master accepts them, exercising response-stability assertions.

## What this proves—and what it does not

This is evidence that the **implemented directed RTL regression passes on the recorded commit**. It is not proof of exhaustive correctness or full AXI4 compliance. The design is an AXI4-Lite subset and does not support bursts or transaction IDs.

Verilator emitted a `SYNCASYNCNET` warning because reset is used in asynchronous-reset logic and assertion sampling. The run still completed successfully. This warning should be reviewed rather than represented as a functional failure.
