## Directed RTL regression

The self-checking testbench `tb/tb_axi_lite_2x2_interconnect.sv` verifies:

1. Master 0 write/read through target 0.
2. Master 1 write/read through target 1.
3. Partial byte-strobe write preserves untouched bytes.
4. Concurrent writes to different targets.
5. Two masters contend for target 0; both writes are read back correctly.
6. Simultaneous read requests contend for target 0.
7. B and R responses are deliberately backpressured for two clock edges before the master accepts them, exercising response-stability assertions.

The observed log included successful readbacks for `0x11223344`, `0xA5C35A3C`, `0x1122CCDD`, `0x0BADF00D`, `0xC001D00D`, `0xCAFE0001`, and `0xCAFE0002`, followed by:

```text
ALL TESTS PASSED: AXI4-Lite 2x2 smoke regression
PASS: Smoke regression completed. Log: results/verilator_smoke.log
```

## Fault-injection negative control

The CI job copies the RTL into a temporary build directory and flips bit 0 of read data routed to master 0. It then runs the same self-checking testbench and **expects the regression to fail with a read-data mismatch**. The job passes only when the checker catches that deliberate corruption. The committed RTL is never modified by the experiment.

This demonstrates checker sensitivity to one representative data-path defect; it does not prove that all defect classes will be detected.

## Limitations of the evidence

- This is an AXI4-Lite subset, not full AXI4. Bursts and transaction IDs are not implemented.
- Passing directed simulation is not exhaustive proof of correctness.
- Verilator reports a `SYNCASYNCNET` warning because reset is used in asynchronous-reset logic and assertion sampling; the regression still passes.
- The UVM source includes two master agents, directed and constrained-random sequences, a reference-memory scoreboard, and transaction covergroups. A real Xcelium UVM run is still required before claiming UVM pass status or reporting a UVM coverage percentage.

## Reproduce locally

RTL smoke regression:

```bash
bash scripts/run_verilator_smoke.sh
```

Fault injection:

```bash
bash scripts/run_fault_injection.sh
```

UVM run on a machine with a compatible Cadence Xcelium/UVM installation:

```bash
SEED=42 bash scripts/run_xcelium_uvm.sh
```

Keep the simulator version, seed, logs, scoreboard summary, and coverage output together when reporting results.
